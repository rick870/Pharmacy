# Sistema de Gestión de Farmacia 💊

Aplicación de escritorio diseñada para el control eficiente de inventarios, gestión de medicamentos y seguimiento de ventas. Este proyecto está desarrollado bajo una arquitectura de capas.

* **Control de Inventario:** Seguimiento en tiempo real de los niveles de stock.
* **Módulo de Ventas:** Interfaz optimizada para el registro y procesamiento de transacciones.
* **Arquitectura Limpia:** Organización por capas (Datos, Negocio, Entidades y Presentación) para facilitar el mantenimiento.

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** C#
* **Framework:**  Windows Forms
* **Base de Datos:** SQL Server
* **Herramientas:** Git, GitHub, Visual Studio

## 🏗️ Estructura del Proyecto

El sistema se divide en las siguientes capas:
* **Farmacia.Presentacion:** Interfaz de usuario y formularios.
* **Farmacia.Negocio:** Lógica principal y reglas del sistema.
* **Farmacia.Datos:** Acceso a datos y conexión con SQL Server.
* **Farmacia.Entidades:** Modelos de datos y estructuras del dominio.
